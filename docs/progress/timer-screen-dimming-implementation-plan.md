Add pure helper:

```ts
export function getDimmedBrightnessTarget(
  currentBrightness: number,
  dimmedBrightnessPercent: number,
) {

}
```

## Step 3: Add dimming hook without app lifecycle

### Goal

Create a reusable hook that schedules dimming and restores brightness.

### Likely files

- `src/hooks/useScreenDimming.ts`
- `src/hooks/useScreenDimming.test.tsx`
- `src/test/setupTests.ts` for mocking `expo-brightness`

### Hook API

```ts
type Params = {
  enabled: boolean
  dimmedBrightnessPercent: number
  shouldDim: boolean
  delayMs?: number
}
```

### Behavior

- If `enabled && shouldDim`, start a 5 second timer.
- Before the delay finishes, do nothing.
- After the delay:
  - read current brightness with `Brightness.getBrightnessAsync()`
  - store the brightness to restore later
  - set brightness to `Math.min(currentBrightness, configuredDimmedBrightness)`
- If `enabled` or `shouldDim` becomes false:
  - clear pending timeout
  - restore stored brightness immediately, if brightness was dimmed
- On unmount:
  - clear pending timeout
  - restore stored brightness if needed

### Unit tests

Cover:

1. Does nothing when disabled.
2. Does nothing before the delay completes.
3. Dims after the delay.
4. Uses `Math.min(currentBrightness, configuredBrightness)`.
5. Cancels pending dimming if `shouldDim` becomes false before the delay.
6. Restores brightness when `shouldDim` becomes false after dimming.
7. Restores brightness on unmount.

### Manual UI test

No visible app behavior yet. Run unit tests.

## Step 4: Add app lifecycle handling

### Goal

Restore brightness when the app leaves the active foreground state.

### Likely files

- `src/hooks/useScreenDimming.ts`
- `src/hooks/useScreenDimming.test.tsx`

### Behavior

Use React Native `AppState`.

- If app state changes away from `active`, restore brightness immediately.
- When app becomes `active` again and `enabled && shouldDim` is still true, start the normal 5 second delay again.
- This should cover iOS `inactive` states such as Notification Center, multitasking view, and incoming calls if React Native reports the state change.

### Unit tests

1. Dims while active.

4. Re-schedules dimming when app returns to `active`.

## Step 5: Wire dimming into the timer screen

### Goal

Activate screen dimming while focus or break timers are running.

### Likely files

- `src/components/home/TimerScene.tsx`
- `src/components/home/TimerScene.test.tsx`

### Implementation notes

Read settings from the store:

```ts
const screenDimmingEnabled = useStore((state) => state.screenDimmingEnabled)
const dimmedBrightnessPercent = useStore(
  (state) => state.dimmedBrightnessPercent,
)
```

For both focus and break timers, dimming should depend only on timer status:

```ts
const shouldDim = status === "running"
```

Call:

```ts
useScreenDimming({
  enabled: screenDimmingEnabled,
  dimmedBrightnessPercent,
  shouldDim,
})
```

Dimming is independent of focus controls visibility.

### Unit tests

Mock `useScreenDimming` in `TimerScene` tests and cover:

1. Setting disabled -> hook receives `enabled: false`.
2. Focus running -> `shouldDim: true`.
3. Break running -> `shouldDim: true`.
4. Focus paused -> `shouldDim: false`.
5. Focus idle -> `shouldDim: false`.
6. Timer done -> `shouldDim: false`.

### Manual UI test

1. Enable dimming in settings and set brightness to 15%.
2. Start focus timer.
3. Wait 5 seconds and verify brightness dims.
4. Tap screen and verify brightness restores immediately.
5. Wait 5 seconds while timer is still running and verify brightness dims again.
6. Pause timer and verify brightness restores.
7. Resume timer and verify dimming happens again after 5 seconds.
8. Repeat with break timer.
